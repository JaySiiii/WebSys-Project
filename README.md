# WebSys-Project

## **Project Desciption**:  
A project for Web Systems and Technology Course of Bachelor of Science in Computer Science 2nd Year

### **Website Title**:  
 The Box Cinema  


### **Website description**:  
 A website for streaming movies or series from different sources. It also functions as a hub for movie enthusiast and casual watchers to interact, socialize and share their ideas by creating a community through comments on each movie pages.
